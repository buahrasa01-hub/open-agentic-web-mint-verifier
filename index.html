Mint Verifier

Check a BSC contract before you mint, buy, or send anything. Paste a contract address — the page reads its public on-chain facts and gives a plain verdict.

Verify a contract

Try it: 0x10b80088fDAf9363d83671BE66b64f231f9e92f6 is a real token contract. 0x0000000000000000000000000000000000000000 is not a contract at all.

What it checks

  • Whether any contract code exists at the address.
  • Token metadata: name, symbol, decimals, total supply.
  • Whether one owner address controls the contract.
  • Whether the contract is paused, and its max supply.
  • Whether mint-like functions are likely present (found in the deployed bytecode).

What it cannot do

  • It cannot mint, buy, or send anything — there is no wallet here, and nothing is signed.
  • It cannot read off-chain promises, audit reports, or unverified source code.
  • It cannot guarantee safety. A contract can pass every public check and still be dangerous.
  • It only reads BNB Smart Chain (chain id 56).

All checks run in your browser against the public BSC endpoint https://bsc-dataseed1.binance.org. No address you enter is sent anywhere else.
